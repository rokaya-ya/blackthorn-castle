# Blackthorn Castle

A gothic fantasy murder mystery comic. One library, one growing story.

Read: **https://rokaya-ya.github.io/blackthorn-castle/**

The library contains all 150 pages of Chapters 1-4. The reader supports vertical scrolling, page mode, chapter switching, full-image access and device-local reading progress.

## Publishing

See [PUBLISHING.md](PUBLISHING.md) for the reviewed-chapter importer and permanent-link deployment workflow. Run `python tools/validate_library.py` before publishing. Only completed chapters whose master hashes match the passing production review can be registered.

## Provenance

Chapters 1-3 and the original website assets are preserved from [the existing Blackthorn Castle project](https://github.com/moiz-q/blackthorn-castle), revision b304ce0a4715147a6dd7f1f523997929cce36dc1, at the comic owner's request. Their original artwork has not been changed. Chapter 4 is the completed 35-page production from the local comic project. The new site and repository are separate from the Secret Lair game.

Original production scripts, reference portraits, rejected art and private storyline notes remain in the local production project and are not published here.
